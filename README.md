COVID-19 Impact Analysis & Future Case Prediction

This project analyzes COVID-19 global and India-specific patient data to study infection trends, recovery rates, and forecast future cases using machine learning techniques.

---

Dataset
- Sources: CSV & Excel files containing:
  - Confirmed Cases  
  - Deaths  
  - Recovered Patients  
- Data includes both **Global** and **India-specific** statistics.

---

 Technologies Used
- **pandas:** Data loading, cleaning, merging.
- **plotly:** Interactive visualizations of COVID-19 trends.
- **Facebook Prophet:** Time series forecasting for future case predictions.

---
Project Workflow
1. Data Collection from CSV & Excel files.
2. Data Preprocessing (Cleaning, Aggregating, Formatting).
3. Data Visualization:
   - Infection Growth Trends  
   - Recovery & Death Rates  
   - Country-wise Comparisons  
4. Forecasting Future Cases (7 days ahead):
   - Using Facebook Prophet for time-series prediction.
5. Visualization of Predictions with Actual Data.

---

 Features
- Trend Analysis (Confirmed, Recovered, Deaths).
- Country-specific interactive charts.
- Short-term prediction (next week cases).
- Highly customizable forecasting pipeline.
